================================================================================
          PANDUAN SETUP MANDIRI JALANSAFE HMVC REACT VIA TERMINAL
        TUGAS AKHIR PRAKTIKUM PABW - MODUL 9 (HMVC REACT STARTER KIT)
================================================================================

Aplikasi JalanSafe adalah Sistem Informasi Pengelolaan dan Pelaporan Kerusakan
Jalan Kota Cerdas berbasis Arsitektur Modular HMVC (Hierarchical Model View
Controller) dengan antarmuka modern React 19, TypeScript, Inertia.js 2,
Tailwind CSS, dan komponen shadcn/ui.

Ikuti langkah-langkah di bawah ini melalui terminal (Command Prompt, PowerShell,
atau Terminal Linux/macOS) untuk menjalankan dan mempelajari aplikasi:

--------------------------------------------------------------------------------
1. PRASYARAT
--------------------------------------------------------------------------------
Pastikan di komputer sudah terinstal:
- PHP versi 8.2 atau lebih tinggi (cek: php -v)
- Composer versi 2.x (cek: composer -v)
- Node.js versi 18+ / 20+ dan npm (cek: node -v && npm -v)

--------------------------------------------------------------------------------
2. URUTAN PERINTAH SETUP VIA TERMINAL
--------------------------------------------------------------------------------

Langkah 1: Salin file konfigurasi lingkungan (.env)
   - Windows CMD    : copy .env.example .env
   - PowerShell/Bash: cp .env.example .env

Langkah 2: Instal dependensi PHP (Composer)
   composer install

Langkah 3: Generate Application Key
   php artisan key:generate

Langkah 4: Jalankan migrasi basis data SQLite dan seeder data awal
   php artisan migrate:fresh --seed
   (Jika muncul konfirmasi pembuatan file database SQLite, ketik 'yes' lalu Enter)

Langkah 5: Hubungkan symbolic link public storage (agar foto laporan kerusakan tampil)
   php artisan storage:link

Langkah 6: Instal dependensi JavaScript/React (npm)
   npm install

Langkah 7: Kompilasi aset frontend React
   Opsi A (Mode Development):
      npm run dev
   ATAU
   Opsi B (Kompilasi Sekali):
      npm run build

Langkah 8: Nyalakan web server lokal Laravel
   php artisan serve

Akses aplikasi di browser:
   http://127.0.0.1:8000

--------------------------------------------------------------------------------
3. INFORMASI AKUN LOGIN (SUDAH TERSEDIA DI SEEDER DATABASE)
--------------------------------------------------------------------------------
1) Akun Aparatur Dinas Bina Marga (Admin):
   - Email    : admin@example.com
   - Password : password
   - Hak Akses:
     * Mengelola Master Data Ruas Jalan (CRUD Synchronous Inertia.js pada modul DataJalan).
     * Mengubah dan memverifikasi status penanganan laporan jalan (Ditinjau, Diperbaiki, Selesai).
     * Mengakses dashboard statistik kota cerdas.

2) Akun Warga Masyarakat Pelapor (User):
   - Email    : user@example.com
   - Password : password
   - Hak Akses:
     * Melaporkan kerusakan jalan secara cepat menggunakan dialog modal AJAX + upload foto bukti (CRUD Asynchronous pada modul PelaporanJalan).
     * Melihat riwayat laporan, mengedit deskripsi, atau membatalkan laporan secara instan tanpa reload browser.
     * Tidak memiliki hak mengedit data ruas jalan (otomatis ditolak 403 Forbidden).

--------------------------------------------------------------------------------
4. VERIFIKASI PENGUJIAN OTOMATIS (FEATURE TEST)
--------------------------------------------------------------------------------
Untuk menguji seluruh skenario fungsional dan keamanan sistem:
   php artisan test tests/Feature/JalanSafeTest.php

Seluruh pengujian mencakup:
- Pengalihan tamu ke halaman login
- Proteksi rute admin dari akses akun warga (HTTP 403 Forbidden)
- Operasi CRUD Inertia pada master data ruas jalan
- Operasi CRUD AJAX pada pelaporan kerusakan jalan
- Pengunggahan foto bukti ke storage dan pembersihan berkas saat data dihapus
